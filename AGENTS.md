# GasStation
Standalone TypeScript / Three.js gas-station PWA. Reuses small helpers from RestaurantCommon, with its own simulation and saves. Documentation is Czech; identifiers and comments English.
Run npm test here; build with npm run build after installing dependencies in RestaurantCommon. Shared typecheck is npm run typecheck in RestaurantCommon.
Keep simulation independent of DOM. Test money, traffic reservations, stock, sanitation and save behavior. Do not modify sibling games without coordinating with their owner.
